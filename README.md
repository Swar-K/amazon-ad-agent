# Put your footage here

Accepted: photos (.jpg .png .webp) and clips (.mp4 .mov .webm).

**What works best**
- 8+ photos and 90+ seconds of clips *you* shoot of the actual product: hands only, no faces
  (rotating it, opening the lid, putting it in a cup holder, pouring, close-ups of seams/buttons/logo).
  Own footage is what makes the video original, avoids repetitive-looking shots, and is the safest option for YouTube.
- Brand press-kit images (check the brand's media terms) are the next best.
- Shoot landscape if you can; portrait clips are fine (the editor fills the sides with a soft blur).
- Keep each file under 100 MB (GitHub limit). Compress clips to 1080p H.264 first, or use Git LFS.

**The agent automatically refuses**
- anything showing a human face (even on packaging) or a reflection of one,
- screenshots/images containing prices, star ratings, review text or Amazon page UI.

Nothing here is scraped; the agent only uses the files you add.
